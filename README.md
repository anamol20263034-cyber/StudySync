# 📚 StudySync - Collaborative Learning Space


StudySync is a modern, real-time collaborative learning web application designed to bring students and peers together. It features a unified frontend and backend setup equipped with interactive tools to enhance collaborative study sessions.

---

## 🚀 Features

* **Interactive Whiteboard**: Draw, brainstorm, and collaborate visually in real time.
* **Real-time Messaging / Communication**: Integrated messaging helper utilities and smooth UI toasts.
* **Responsive Modern UI**: Built with clean CSS styling, featuring a polished layout optimized for any screen size.
* **Robust Backend API**: Powered by Node.js, Express, and CORS for secure and seamless client-server communication.

---

## 🛠️ Tech Stack

* **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS DOM manipulation)
* **Backend**: Node.js, Express.js, CORS
* **Environment / Tools**: Visual Studio Code, npm, Windows PowerShell
